# Privacy Policy

**Last Updated: November 2026**

This Privacy Policy describes how **Whoz** ("we", "our", or "the Bot") handles data when you interact with our services on Discord.

---

## 1. Information We Collect
Whoz adheres to a strict data minimization policy. We only collect the minimal data required to provide gameplay functionality:
- **Discord User ID:** Used exclusively to maintain active game sessions and track personal statistics (total games, win/loss record).
- **Discord Server ID:** Used solely to store guild-specific settings (such as the default language chosen by administrators).
- **In-Game Answers:** Temporarily stored in memory during an active game session and cleared immediately upon session completion or timeout.

We **do not** collect personal identities, emails, passwords, private message content, IP addresses, or payment details.

## 2. How We Use Information
The collected data is used exclusively for:
- Delivering interactive game sessions.
- Displaying personal statistics when `/whoz stats` is executed.
- Remembering server language preferences when `/whoz language` is used.

## 3. Data Retention & Deletion
- Game session data is kept strictly in volatile memory and wiped after each game or 10 minutes of inactivity.
- Statistical data is retained until a reset is requested.
- Users or Server Owners may request complete deletion of their data at any time via [https://whoz.sotarstudio.online](https://whoz.sotarstudio.online).

## 4. Third-Party Sharing
We do not sell, rent, trade, or share user data with any third parties.

## 5. Contact
If you have questions regarding this Privacy Policy, please visit [https://whoz.sotarstudio.online](https://whoz.sotarstudio.online).
